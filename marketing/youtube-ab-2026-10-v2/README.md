# Verceltics YouTube thumbnails — second set

Eight distinct concepts created October 4, 2026 using built-in imagegen, following feedback that the first white variant was preferred. Numbers 01–08 are a new independent set.

`00-compare-all.jpg` is a numbered comparison sheet; `01-*.jpg` through `08-*.jpg` are upload-ready 1280 × 720 files. Original generated PNGs are retained in `originals/`. JPEG normalization and the comparison sheet were made with sips and ImageMagick; thumbnail artwork was generated with the built-in imagegen tool.

App screens are references with sample data. These are promotional compositions, and generated small UI details and logo shapes may vary from the exact source.
