# Reviewed iOS release notes

Before a future release, add exactly one `## ios-vX.Y` section with reviewed
user-facing notes. The version must match the iOS project's `MARKETING_VERSION`.
The same notes become the GitHub release body and App Store What's New text.

There is no release tag or approved release-note section prepared by this setup.
