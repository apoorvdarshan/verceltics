# App Store product page header image (IOS_UPLOAD_CREATIVE_ASSETS)

At most one PNG here, exactly 3840×1646, without an alpha channel. With
`IOS_UPLOAD_CREATIVE_ASSETS` on, a release uploads it to the app's Asset Library
once, sends it to App Review in a review submission of its own, and places it on
the version's en-US product page once Apple approves it. Without an image this
slot is left alone. To change the image, commit it under a new file name. See
[store/README.md](../../../README.md#header-and-search-results-images-ios).
